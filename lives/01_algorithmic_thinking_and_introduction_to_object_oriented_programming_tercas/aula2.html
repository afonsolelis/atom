Variáveis e tipos de dados

nome = "Ana" # str — texto idade = 22 # int — inteiro nota = 8.5 # float — decimal ativo = True # bool — verdadeiro/falso
  • Python é dinamicamente tipado: o tipo é inferido pelo valor.
  • Use type(x) para descobrir o tipo de qualquer variável.
  • Nomes de variáveis devem ser descritivos — nota_final é melhor que nf.

Condicionais: if / elif / else

def conceito(nota): if nota >= 9.0: return "A" elif nota >= 7.0: return "B" elif nota >= 6.0: return "C" else: return "Reprovado"

Avalie apenas um bloco: o primeiro cujo teste for verdadeiro.

Repetição: for e while

# for — quantidade conhecida soma = 0 for n in range(1, 11): soma += n print(soma) # -> 55 # while — quantidade desconhecida senha = "" while senha != "1234": senha = input("Senha: ")

Use for quando sabe quantas iterações; while quando depende de uma condição.

Listas para sequências; dicionários para dados estruturados com rótulo.

Conteúdo

Funções: empacotando lógica

def total_por_categoria(gastos, categoria): return sum( g["valor"] for g in gastos if g["categoria"] == categoria )
  • DRY — Don't Repeat Yourself: escreva a lógica uma vez, reutilize muitas.
  • Funções com nomes claros são autodocumentação.
  • Parâmetros com tipos e retorno explícitos evitam bugs silenciosos.

Mão na massa

Mini-programa: controle de gastos

gastos = [ {"categoria": "alimentação", "valor": 45.5, "dia": 3}, {"categoria": "transporte", "valor": 120.0, "dia": 3}, {"categoria": "alimentação", "valor": 38.0, "dia": 4}, {"categoria": "lazer", "valor": 200.0, "dia": 5}, ] print(f"Alimentação: R$ {total_por_categoria(gastos, 'alimentação'):.2f}")

Resultado: Alimentação: R$ 83.50

Comparando linguagens · Python vs Rust

O mesmo filtro em Rust

let total_alimentacao: f64 = gastos .iter() .filter(|g| g.categoria == "alimentação") .map(|g| g.valor) .sum(); println!("Alimentação: R$ {:.2}", total_alimentacao);

Em Rust, iteradores são lazy e zero-cost: o compilador os transforma em loops eficientes — sem alocação extra.
