Herança: reaproveitar código

class Animal: def __init__(self, nome): self.nome = nome def falar(self): return "..." class Cachorro(Animal): # herda de Animal def falar(self): return f"{self.nome}: Au au!" class Gato(Animal): def falar(self): return f"{self.nome}: Miau!"

Cachorro e Gato ganham __init__ e nome de graça, do pai Animal.

Conteúdo

super(): estender sem repetir

class Veiculo: def __init__(self, marca): self.marca = marca class Carro(Veiculo): def __init__(self, marca, portas): super().__init__(marca) # reaproveita o pai self.portas = portas

super() chama o construtor da classe-mãe: a especialização só adiciona o que é novo.

Polimorfismo na prática

O mesmo método falar(), chamado da mesma forma, faz coisas diferentes:

animais = [Cachorro("Rex"), Gato("Mimi")] for a in animais: print(a.falar()) # -> Rex: Au au! # -> Mimi: Miau!

O loop não sabe (nem precisa saber) o tipo exato — só confia que todo Animal fala.

Composição: "tem-um" vs "é-um"

Nem tudo é herança. Um Carro não é um Motor — ele tem um Motor:

class Motor: def ligar(self): return "Vrum!" class Carro: def __init__(self): self.motor = Motor() # Carro TEM um Motor def dar_partida(self): return self.motor.ligar()

Regra prática: prefira composição (tem-um) e use herança (é-um) só quando a relação for de verdade.

Mini-projeto

Sistema de biblioteca

class Livro: def __init__(self, titulo): self.titulo = titulo self.disponivel = True class Biblioteca: def __init__(self): self.acervo = [] def adicionar(self, livro): self.acervo.append(livro) def emprestar(self, titulo): for livro in self.acervo: if livro.titulo == titulo and livro.disponivel: livro.disponivel = False return f"Emprestado: {titulo}" return "Indisponível"

Comparando linguagens · Python vs Rust

Polimorfismo em Rust: Traits

Rust troca herança por traits — contratos que qualquer tipo pode implementar, sem hierarquia de classes:

trait Descricao { fn descricao(&self) -> String; } struct Livro { titulo: String, autor: String } struct Revista { nome: String, edicao: u32 } impl Descricao for Livro { fn descricao(&self) -> String { format!("📖 {} — {}", self.titulo, self.autor) } } impl Descricao for Revista { fn descricao(&self) -> String { format!("📰 {} nº{}", self.nome, self.edicao) } }

Python usa herança + duck typing; Rust usa traits + composição. Dois caminhos para o mesmo princípio: "o mesmo método, comportamentos diferentes".
